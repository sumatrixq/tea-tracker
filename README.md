# 🍵 Чайный путь 茶道

Android-приложение для заваривания чая и кофе с настраиваемыми таймерами. Можно вести сразу несколько таймеров, выбирать звуки сигнала и настраивать вибрацию. Оформлено в красно-золотом китайском стиле.

> Индивидуальный проект по специальности 09.02.07 «Информационные системы и программирование».

## Скачать

1. Откройте [последний релиз](https://github.com/sumatrixq/tea-tracker/releases/latest).
2. В разделе **Assets** скачайте файл `chai-puti.apk`.
3. Откройте файл на телефоне и разрешите установку из неизвестных источников.

Требуется телефон на Android.

## Возможности

- **Каталог сортов.** 8 видов чая (улун, пуэр, зелёный, белый, красный) и 5 способов приготовления кофе.
- **Свои сорта.** Кнопка ＋: название, категория, температура, вес, объём воды, заметки, звук сигнала.
- **Несколько таймеров одновременно.** Запускайте чай и кофе параллельно: у каждого сорта свой таймер. Таймеры продолжают идти, пока вы листаете приложение.
- **Запуск пачкой.** Кнопка ☑ в списке: отметьте несколько сортов и запустите все таймеры одним нажатием.
- **Экран «Таймеры».** Все активные таймеры на одном экране: пауза, старт, правка времени, остановка. Есть «Пауза всех» и «Продолжить все».
- **Свои таймеры.** Для каждого сорта своя цепочка проливов в секундах, например `10, 15, 20, 30, 45`. Во время заваривания время можно менять кнопками −/+ (шаг 5, 10, 15 или 30 секунд на выбор).
- **Звуки сигнала.** Колокольчик, гонг, перезвон, поющая чаша, сигнал, системный звук или тишина. Звук можно задать для всех таймеров, для отдельного сорта или для одного запущенного таймера. Есть кнопка «Проверить звук».
- **Вибрация.** Короткая, обычная или длинная, включается и выключается в настройках.
- **Уведомления** об окончании пролива приходят, даже если приложение свёрнуто или экран выключен.
- **Оформление.** Три темы: «Императорский», «Чёрный лак», «Рисовая бумага». Температура в °C или °F.
- **Хранение данных.** Всё сохраняется на устройстве. Чтобы изменить сорт, нажмите на его карточку и удерживайте или нажмите ✎.

## Как пользоваться

1. Выберите сорт на главном экране: откроется его таймер. Нажмите «Старт».
2. Чтобы вести несколько таймеров, вернитесь к списку и запустите другой сорт. Либо нажмите ☑, отметьте сорта и запустите их вместе.
3. Следить за всеми таймерами можно на экране «Таймеры»: нажмите плашку «Активных таймеров» в списке или значок ⏱ в шапке.
4. Когда пролив закончится, придёт уведомление со звуком, и телефон завибрирует.
5. Звук и вибрацию настраивает ⚙ «Настройки». Звук отдельного сорта выбирается при его редактировании, а звук одного таймера, на экране самого таймера (строка «Звук»).

## Для разработчиков

### Стек

React Native + Expo (SDK 52), TypeScript, expo-notifications, expo-keep-awake, AsyncStorage.

### Запуск для разработки

```bash
npm install
npx expo start        # откройте в Expo Go или на эмуляторе
npm run typecheck
```

> Уведомления по расписанию и собственные звуки нужно проверять на собранном APK. В Expo Go свои звуки недоступны.

### Сборка APK

**Через GitHub Actions (проще всего).**
Запушьте проект в `main`: workflow `.github/workflows/build-apk.yml` соберёт `chai-puti.apk`. Скачать его можно в **Actions → нужный запуск → Artifacts**.

Чтобы APK появился в **Releases**, создайте тег:

```bash
git tag v1.1.0
git push origin v1.1.0
```

**Локально** (нужны JDK 17 и Android SDK):

```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

APK подписывается debug-ключом. Для защиты проекта и установки на телефон этого достаточно.

### Как устроены таймеры и звуки

- Все таймеры хранит `TimersProvider` (`src/timers.tsx`). Один общий тик раз в 250 мс считает остаток по метке окончания, поэтому время не «уплывает» при сворачивании приложения.
- Для каждого таймера планируется своё системное уведомление, так что сигнал приходит и в фоне.
- На Android 8+ звук и вибрацию задаёт канал уведомлений, и после создания его нельзя изменить. Поэтому для каждой пары «звук + вибрация» лениво создаётся отдельный канал (`src/notifications.ts`).
- Собственные звуки лежат в `assets/sounds` и подключаются плагином `expo-notifications` в `app.json`. Чтобы добавить звук, положите `.wav`, впишите его в `app.json` и добавьте запись в `SOUNDS` (`src/sounds.ts`) и тип `SoundKey` (`src/types.ts`).
- Приоритет звука: таймер → сорт → настройки.

### Структура проекта

```
App.tsx                  навигация и состояние
src/data.ts              стандартные сорта
src/storage.ts           сохранение данных
src/timers.tsx           хранилище нескольких таймеров
src/sounds.ts            список звуков и рисунки вибрации
src/notifications.ts     локальные уведомления и каналы
src/theme.ts, ui.tsx     палитры и компоненты в китайском стиле
src/screens/             Home, Brew (таймер), Timers (все таймеры), Editor, SettingsScreen
assets/sounds/           звуки сигнала (.wav)
```
