🍵 Чайный путь 茶道

Android-приложение для заваривания чая и кофе с настраиваемыми таймерами. Оформлено в красно-золотом китайском стиле.

Индивидуальный проект по специальности 09.02.07 «Информационные системы и программирование».

Скачать
Откройте последний релиз.
В разделе Assets скачайте файл chai-puti.apk.
Откройте файл на телефоне и разрешите установку из неизвестных источников.

Требуется телефон на Android.

Возможности
Каталог сортов. 8 видов чая (улун, пуэр, зелёный, белый, красный) и 5 способов приготовления кофе.
Свои сорта. Кнопка ＋: название, категория, температура, вес, объём воды, заметки.
Свои таймеры. Для каждого сорта своя цепочка проливов в секундах, например 10, 15, 20, 30, 45. Во время заваривания время можно менять кнопками −10 с / +10 с.
Уведомления. Сообщают об окончании пролива, даже если приложение свёрнуто или экран выключен.
Вибрация по окончании пролива. Экран не гаснет, пока идёт таймер.
Оформление. Три темы: «Императорский», «Чёрный лак», «Рисовая бумага».
Настройки. Переключение °C / °F, включение и выключение уведомлений и вибрации.
Хранение данных. Всё сохраняется на устройстве. Чтобы изменить сорт, нажмите на его карточку и удерживайте или нажмите ✎.
Как пользоваться
Выберите сорт на главном экране.
Нажмите старт и заливайте чай водой.
Когда пролив закончится, придёт уведомление и телефон завибрирует.
Если нужен другой сорт или свои тайминги, нажмите ＋ и создайте его.
Для разработчиков
Стек

React Native + Expo (SDK 52), TypeScript, expo-notifications, expo-keep-awake, AsyncStorage.

Запуск для разработки
bash
npm install
npx expo start        # откройте в Expo Go или на эмуляторе
npm run typecheck

Уведомления по расписанию лучше проверять на собранном APK, а не в Expo Go.

Сборка APK

Через GitHub Actions (проще всего). Запушьте проект в main: workflow .github/workflows/build-apk.yml соберёт chai-puti.apk. Скачать его можно в Actions → нужный запуск → Artifacts.

Чтобы APK появился в Releases, создайте тег:

bash
git tag v1.0.0
git push origin v1.0.0

Локально (нужны JDK 17 и Android SDK):

bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk

APK подписывается debug-ключом. Для защиты проекта и установки на телефон этого достаточно.
