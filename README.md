# Чайный путь 茶道

Мобильное приложение (Android) — трекер заваривания чая и кофе с настраиваемыми таймерами в красно-золотом китайском стиле.
Индивидуальный проект, специальность 09.02.07 «Информационные системы и программирование».

## Возможности

- Каталог сортов: 8 чаёв (улун, пуэр, зелёный, белый, красный) и 5 способов приготовления кофе.
- **Свои сорта**: кнопка ＋ — название, категория, температура, вес, объём воды, заметки.
- **Кастомные таймеры**: для каждого сорта своя цепочка проливов/этапов в секундах (например, `10, 15, 20, 30, 45`). Во время заваривания время можно менять кнопками −10 с / +10 с.
- **Уведомления** об окончании пролива — приходят, даже если приложение свёрнуто или экран выключен.
- Вибрация по окончании, экран не гаснет во время таймера.
- **Кастомизация**: 3 темы (Императорский, Чёрный лак, Рисовая бумага), °C/°F, переключатели уведомлений и вибрации.
- Данные хранятся на устройстве (AsyncStorage), долгое нажатие на карточку или ✎ — редактирование.

## Стек

React Native + Expo (SDK 52), TypeScript, expo-notifications, expo-keep-awake, AsyncStorage.

## Запуск для разработки

```bash
npm install
npx expo start        # откройте в Expo Go или на эмуляторе
npm run typecheck
```

> Уведомления по расписанию лучше проверять на собранном APK, а не в Expo Go.

## Сборка APK

**Через GitHub Actions (проще всего).** Загрузите проект в репозиторий и запушьте в `main` — workflow
`.github/workflows/build-apk.yml` соберёт `chai-puti.apk`. Скачать его можно в Actions → запуск → Artifacts.
Чтобы APK появился в **Releases**, создайте тег:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

**Локально** (нужны JDK 17 и Android SDK):

```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

APK подписывается debug-ключом — для защиты проекта и установки на телефон этого достаточно
(на телефоне разрешите установку из неизвестных источников).
